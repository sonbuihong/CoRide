# CoRide cross-platform UI audit — 2026-08-26

## Scope

Reviewed `apps/web`, `apps/mobile`, `packages`, workspace configuration and the former `MASTER.md`. Baseline: 107 Web source files, 120 Mobile app/source/component files, 3,508 `className` occurrences, 29 `StyleSheet.create` blocks, 94 inline object styles, 45 `Platform.OS` branches, 79 explicit font sizes, 178 radii, 256 background colors, 232 padding declarations and 202 margin declarations.

## Findings

1. **Split truth:** Web CSS variables, both Tailwind configs, Mobile runtime tokens and Master described different scales. Master described a dark slate product while current apps are light CoRide blue.
2. **Hardcoded colors:** dominant literals include `#1D1D1F`, `#0071E3`, `#F5F5F7`, `#3B82F6`, `#34C759`, red variants and slate grays. Mobile hotspots: `ride/[id].tsx`, `ProfileContent.tsx`, `ride-hailing.tsx`, `RideInfoPanel.tsx`, `driver/register.tsx`. Web hotspots: ride post/detail/list, profile/wallet and structured-address input.
3. **Scale drift:** spacing clusters around 4/8/12/16/20/24/32 but names differ. Font sizes 11/13/15/17/18/19/20 and radius 5/6/10/11/12/14/16/18/20/24/26 appear ad hoc.
4. **Duplication:** buttons, icon buttons, cards/surfaces, pills, input rows, headers, state views, profile rows and ride cards are styled per screen despite existing `App*` primitives.
5. **Responsive:** no 390×844/375×812 frame was found. Most layout is Flexbox. `MobileAppHeader` is the only dimension-hook user. Fixed 40–56 values are mostly icons/touch controls; text controls still need review for height versus min-height.
6. **Absolute layout:** concentrated in valid map overlays, markers, floating controls, badges and tab indicators. Ride detail, both home maps, active ride and place selection remain device-test risks because overlays and insets interact.
7. **Safe area:** provider usage is inconsistent. Chat used React Native `SafeAreaView` plus Android `paddingTop: 40`; this was migrated. Other roots remain incremental work.
8. **Platform code:** keyboard, status bar, datetime picker, SecureStore/localStorage, emulator networking and native maps are valid differences. Browser APIs are mostly isolated in `.web.tsx` or guarded branches. Search/create have guarded Web input CSS; ProfileContent has guarded `window.confirm`.
9. **Android/iOS risk:** fixed text heights, disabled font scaling, manual top offsets, mixed safe-area providers, keyboard offsets and map overlays are the main risks—not missing platform-specific component files.
10. **Fonts:** Mobile loads Space Mono and FontAwesome only, not Be Vietnam Pro/Noto Sans. Production UI effectively uses system fonts.

## Foundation migrated

Shared semantic tokens and Tailwind preset were added and connected without removing legacy classes. Mobile tokens now adapt the shared package through compatibility aliases. Native shadow, Card and Divider primitives were added. Button accepts children while preserving `title`; Screen gained optional edges/scroll/keyboard/gutter; AppText uses shared type values and bounded accessibility scaling. The chat Android top magic number was removed.

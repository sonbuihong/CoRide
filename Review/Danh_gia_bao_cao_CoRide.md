# Đánh giá và kế hoạch chỉnh sửa báo cáo ĐATN CoRide

> Căn cứ: - Hướng dẫn ĐATN Đại học Phenikaa. - Báo cáo CoRide hiện tại.

## Đánh giá tổng quan

-   Mức hoàn thiện: **88--92/100** theo yêu cầu của trường.
-   Mức kỹ thuật: **75--80/100** nếu đánh giá theo chuẩn Software
    Engineering.

## Đánh giá theo từng phần

### Phần đầu

-   [x] Bìa đúng mẫu.
-   [x] Tóm tắt đầy đủ.
-   [ ] Bổ sung số liệu định lượng (số Use Case, API, bảng dữ liệu...).

### Mở đầu

-   [x] Lý do chọn đề tài.
-   [x] Mục tiêu.
-   [ ] Thêm Research Question.

### Chương 1

Ưu điểm - Research Gap. - Related Work. - Position của đề tài.

Thiếu - Bảng so sánh Grab / Be / BlaBlaCar / CoRide.

### Chương 2

Ưu điểm - Bao phủ đầy đủ công nghệ.

Thiếu - Bảng lý do lựa chọn từng công nghệ. - Có thể rút gọn phần lý
thuyết dài.

### Chương 3

Ưu điểm - Use Case - Activity - Sequence - State - Business Rules

Thiếu - Class Diagram - Package Diagram - Component Diagram - Domain
Model - CRUD Matrix

### Chương 4

Thiếu - C4 Model - Deployment Diagram - JWT Authentication Flow - Redis
Cache Flow - ERD trình bày đẹp hơn

### Chương 5

Thiếu - Folder Structure - Module Dependency - Demo code - Pseudocode xử
lý Race Condition

### Chương 6

Thiếu - Unit Test - Integration Test - API Test - Performance Test -
Stress Test - Concurrent Booking Test - Security Test

### Kết luận

Bổ sung: - Đóng góp kỹ thuật. - Đóng góp khoa học. - Định hướng phát
triển.
